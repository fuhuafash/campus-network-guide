# 🪧 MAC 检测原理

在校园网多设备检测的各种技术手段中，**MAC 检测**是二层接入场景中最直接的手段，常与 TTL、DHCP 指纹、流量特征等配合使用。

## ❓ 什么是 MAC

MAC（Media Access Control Address）是数据链路层地址，用于同一局域网内以太网帧的寻址。一个 MAC 地址长度为 **48 位（6 字节）**，通常写成 12 位十六进制数，例如 `00:1A:2B:3C:4D:5E`。

### MAC 地址结构

| 部分 | 长度 | 含义 |
| :--- | :--- | :--- |
| OUI | 前 3 字节 | 组织唯一标识符，可查询厂商 |
| NIC Specific | 后 3 字节 | 厂商分配给网卡的编号 |
| I/G 位 | 第 1 字节 bit0 | 0 单播，1 组播 |
| U/L 位 | 第 1 字节 bit1 | 0 全局管理，1 本地管理 |

### 📒 常见厂商 OUI 前缀址类型

| 厂商 | 常见 OUI 前缀 | 典型设备 |
| :--- | :--- | :--- |
| Apple | `3C:22:FB`、`A4:83:E7`、`F0:18:98`  | iPhone、iPad、Mac |
| Samsung | `00:1A:8A`、`34:23:BA`、`5C:0A:5B`  | 手机、平板 |
| Huawei | `00:E0:FC`、`28:6E:D4`、`48:DB:50`  | 手机、路由器 |
| Xiaomi | `00:9E:C8`、`28:6C:07`、`64:CC:2E`  | 手机、IoT 设备 |
| Intel | `00:1B:21`、`3C:97:0E`、`A4:5E:60`  | 笔记本网卡 |
| TP-Link | `00:1D:0F`、`14:CC:20`、`EC:08:6B`  | 路由器 |
| Realtek | `00:E0:4C`、`52:54:00`  | 网卡 |
| 随机 MAC | `02:...`、`06:...`、`0A:...`、`0E:...`  | 私有隐私随机 MAC |

## 🔬 校园网检测 MAC 的原理

校园网认证网关或计费系统会在二层接入处记录源 MAC，检测服务商通常会维护一个 MAC 特征库，用于识别设备类型，这个特征库包含常见厂商的 OUI 前缀，单靠 MAC 检测很难发现多设备，需要结合 TTL、DHCP 指纹、User-Agent 等三层或应用层特征。

| 其他手段判断的设备类型 | 抓取的 MAC 特征 | 校园网网关判定 |
| :--- | :--- | :--- |
| Windows 电脑 | 源 MAC = 电脑物理 MAC 或随机 MAC | 唯一设备 |
| Android 手机 | 源 MAC = 电脑物理 MAC | ⚠️ **封禁或增加封禁概率** |
