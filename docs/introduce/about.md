# ❓ 关于本项目

这是一份面向学生与网络爱好者的开源技术文档，旨在深入浅出地讲解校园网多设备检测（NAT 共享限制）的原理，并提供系统化的应对方案与配置教程。


## 💡 项目初衷

在许多校园网环境中，运营商或学校网络中心常通过各种技术手段限制单账号连接设备的数量。这不仅给拥有多台设备（手机、电脑、平板、游戏机、智能家居等）的学习与生活带来了不便，有时也增加了不必要的费用负担。

本项目旨在：
1. **原理讲解**：从网络协议底层原理出发，剖析校园网如何识别多设备共享
2. **提供可行方案**：提供有效的 OpenWrt 及路由器配置


## 📚 本指南涵盖的内容

根据技术层级与实施步骤，本指南主要划分为以下四个板块：

| 模块 | 说明 |
| :--- | :--- |
| **🔍 传统检测** | 详细剖析常见的识别手段，包括 **TTL 递减**、**DHCP 指纹**、**HTTP User-Agent (UA) 特征**、**MAC 地址** 等 |
| **🛡️ 深度包检测** | 针对深度包检测（DPI）识别加密/混淆流量的特点，整理常见的应对思路、防检测策略及潜在风险评估 |
| **🧐 另类检测** | 针对特殊另类检测，尝试解释其原理和给出解决方案 |
| **⚙️ 详细配置** | 提供基于 **OpenWrt** 等主流路由器固件的具体操作步骤、关键防火墙规则与参数调整细节 |
| **🛠️ 排查方法** | 整理自排查流程，帮助快速定位 TTL 防火墙生效情况、UA 泄漏点等疑难杂症 |
